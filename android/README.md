# Warpinator Android

This is an unofficial android client for [Warpinator](https://github.com/linuxmint/warpinator). Forked from [slowscript/warpinator-android](https://github.com/slowscript/warpinator-android) and migrated to Jetpack Compose, Material 3 Expressive and the [Warpinator Perceivers](https://github.com/2-5-perceivers/warpinator) engine.
