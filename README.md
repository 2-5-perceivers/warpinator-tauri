# [Warpinator](https://2-5-perceivers.github.io/#/warpinator)

The fastest way to move files on your local network. A cross-platform suite of Warpinator clients, rewritten for peak performance and seamless device-to-device sharing. Not affiliated with the official Warpinator project, but fully compatible with it.

## Other clients

- The official one: https://github.com/linuxmint/warpinator
- slowscript's Android port: https://github.com/slowscript/warpinator-android
